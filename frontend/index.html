Computer Science in Action

The Three Algorithmic Pillars

CampusPulse runs genuine JavaScript data structure modules that solve genuine concurrency and ordering problems.

⏳
O(1) Enqueue / Dequeue

1. FIFO Waiting List Queue

When capacity fills, students enter a first-in, first-out waiting queue. Implemented with a head-index pointer to prevent array shift overhead. When a confirmed attendee cancels, the queue head is promoted automatically.

Inspect Queue →
⚡
O(1) Composite Hashing

2. Duplicate Prevention Hash Table

Custom polynomial rolling hash table keyed by eventId:userId. Features explicit separate-chaining bucket arrays to resolve collisions and guarantee instant duplicate registration detection.

Inspect Hash Table →
📊
O(n log n) Stable Sort

3. Multi-Criteria Merge Sort

Stable recursive divide-and-conquer sorting algorithm. Re-orders event catalogues and administrative participant rosters by upcoming date, title, available seats, or queue position while maintaining equality stability.
